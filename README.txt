วิธีติดตั้งบน iPhone/iPad (ใช้ออฟไลน์ได้)
1) อัปโหลดทั้งโฟลเดอร์นี้ขึ้นเว็บโฮสต์ HTTPS ฟรี เช่น Netlify Drop (app.netlify.com/drop), Cloudflare Pages หรือ GitHub Pages
2) เปิดลิงก์ด้วย Safari (ต้องต่ออินเทอร์เน็ตครั้งแรก)
3) กดปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม
4) เปิดจากไอคอนบนหน้าจอโฮม ครั้งถัดไปใช้ออฟไลน์ได้เลย
